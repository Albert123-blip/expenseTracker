# Expense Tracker 💰

A responsive personal expense tracker built with HTML, CSS, and Vanilla JavaScript. It helps users manage their income and expenses, monitor their balance, and visualize spending by category.

## Features

- Add income and expense transactions.
- Calculate total income, expenses, and available balance.
- Categorize transactions.
- Filter transactions by type and category.
- Delete individual transactions.
- View spending breakdown using a dynamic donut chart.
- Pagination for transaction history.
- Dark and light theme toggle.
- Save transactions using Local Storage.
- Responsive interface for different screen sizes.
- Currency formatting in USD ($).

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Local Storage
- JSON

## How to Run

1. Clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Start adding your transactions.
